1. Entender MarkItDown

1.1. ¿Qué es MarkItDown?

MarkItDown es una herramienta de Microsoft que permite convertir diferentes tipos de archivos en documentos Markdown.

Su finalidad principal es facilitar que la información contenida en documentos pueda ser utilizada por:

  • Inteligencias artificiales.
  • Modelos de lenguaje.
  • Sistemas de búsqueda.
  • Sistemas de análisis documental.
  • Aplicaciones de procesamiento de información.
  • Sistemas RAG.

Imagina que tienes cien documentos en formatos diferentes: PDF, Word, Excel, PowerPoint, HTML, CSV y JSON. Una inteligencia artificial puede trabajar con muchos de esos formatos, pero resulta muy útil disponer de una representación textual organizada y homogénea. Ahí aparece MarkItDown: extrae contenido y lo convierte a Markdown intentando conservar la estructura importante.

IMPORTANTE: MarkItDown no convierte necesariamente un documento en una copia visual idéntica. Su prioridad es recuperar contenido y estructura para facilitar el análisis automatizado.

1.3. ¿Qué es Markdown?

Markdown es una forma sencilla de escribir documentos estructurados utilizando texto normal y algunos símbolos. El símbolo # representa un título, los guiones - representan listas y los dos asteriscos ** representan texto en negrita. No necesitas un programa especial para leer Markdown: puedes abrir un archivo .md con el Bloc de notas.

Ejemplo de sintaxis Markdown 
# Mi empresa

## Servicios

Ofrecemos los siguientes servicios:

- Limpieza de oficinas.
- Limpieza de comunidades.
- Limpieza de cristales.

**Contacto:** ejemplo@empresa.com

1.4. ¿Por qué es útil para la IA?

Los modelos de lenguaje trabajan principalmente con información textual. Markdown permite representar títulos, subtítulos, párrafos, listas, tablas, enlaces y bloques de código. Esto facilita identificar la organización de la información: una tabla de Excel se convierte en tabla Markdown, una presentación en sucesión de títulos y contenidos, y un Word en estructura de encabezados y párrafos, liberando el dato de su apariencia visual original.

1.5. Diferencias entre formatos

  • PDF: Formato de documento cuya apariencia está diseñada para conservarse.
  • DOCX: Formato de documentos de Microsoft Word.
  • XLSX: Formato de hojas de cálculo de Microsoft Excel.
  • PPTX: Formato de presentaciones de Microsoft PowerPoint.
  • MD: Documento Markdown (representa principalmente contenido textual estructurado).

1.7. Qué puede conservar y qué puede perder

Puede conservar (según formato) Puede perder o simplificar
Texto, títulos, listas, tablas, enlaces, determinados metadatos y orden de determinados elementos. Colores, tipografías, posiciones exactas, animaciones, diseños complejos, información visual, elementos gráficos y relaciones espaciales.

Una conversión no debe considerarse una copia fiel del original.

1.8. Ventajas frente a copiar y pegar

  • Copiar manualmente: Consume tiempo, introduce errores, es difícil de repetir y no resulta práctico para cientos de documentos.
  • MarkItDown: Automatiza la extracción, procesa diferentes formatos, facilita conversiones repetitivas, permite integrarlo con Python y prepara información para IA.

1.9. Preparar documentos para una LLM

LLM significa Large Language Model (modelo de lenguaje grande), como ChatGPT, Claude, Gemini o modelos locales ejecutados con Ollama. Preparar documentos significa convertirlos y organizarlos para facilitar su análisis. IMPORTANTE: Convertir un documento no garantiza que una IA comprenda correctamente toda su información; siempre debemos comprobar los resultados.

3. Instalación de MarkItDown

3.1. Crear la carpeta de trabajo

En PowerShell, creamos la carpeta C:\MarkItDownCurso, entramos en ella y verificamos nuestra ubicación:

PowerShell — Crear y entrar en carpeta
New-Item -ItemType Directory -Path "C:\MarkItDownCurso" -Force
Set-Location "C:\MarkItDownCurso"
Get-Location

Debe aparecer en pantalla: C:\MarkItDownCurso.

3.2. Crear y activar un entorno virtual

Creamos un entorno virtual llamado .venv y lo activamos. Si PowerShell bloquea el script, aplicamos una política temporal únicamente al proceso actual:

PowerShell — Crear y activar .venv
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1

Si funciona, aparecerá el indicador (.venv) PS C:\MarkItDownCurso>. Si PowerShell bloquea la ejecución del script, ejecuta:

PowerShell — Solución a bloqueo de Activate.ps1
Get-ExecutionPolicy -List
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1

Esta modificación afecta únicamente a esa sesión de PowerShell. No es necesario desactivar permanentemente las medidas de seguridad.

3.3. Actualizar Pip

Con el entorno (.venv) activado, actualiza pip antes de instalar:

PowerShell — Actualizar pip
python -m pip install --upgrade pip

3.4. Instalar MarkItDown

Para este curso recomendamos la instalación completa para trabajar con todos los formatos. En entornos profesionales conviene instalar solo las dependencias necesarias:

PowerShell — Opciones de instalación
# Instalación básica:
python -m pip install markitdown

# Instalación completa (recomendada para este curso):
python -m pip install "markitdown[all]"

# Instalación selectiva:
python -m pip install "markitdown[pdf,docx,pptx,xlsx,xls]"
Extras disponibles en la versión consultada (0.1.9):
all, pptx, docx, xlsx, xls, pdf, outlook, audio-transcription, youtube-transcription, az-doc-intel, az-content-understanding.
Los extras son conjuntos de dependencias opcionales, no programas independientes.

3.5. Comprobar la instalación

PowerShell — Verificación de MarkItDown
python -m pip show markitdown
Get-Command markitdown
markitdown --help
markitdown --list-plugins

Nota: Si no hay plugins instalados al ejecutar --list-plugins, no significa que MarkItDown esté averiado.

3.6. Desinstalar y reinstalar

Para desinstalar el paquete, eliminar por completo el entorno virtual (sin borrar tus documentos fuera de .venv) o reinstalar desde cero:

PowerShell — Desinstalar, limpiar y reinstalar
# Desinstalar paquete:
python -m pip uninstall markitdown

# Eliminar entorno completo:
deactivate
Remove-Item -Recurse -Force ".venv"

# Reinstalar desde cero:
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install "markitdown[all]"

4. Primera Conversión

Objetivo: Convertir un archivo de texto en Markdown paso a paso.

  1. Abre PowerShell, activa el entorno virtual y entra en la carpeta C:\MarkItDownCurso.
  2. Crea un archivo de prueba llamado primer_documento.txt, comprueba que existe, conviértelo y ábrelo en el Bloc de notas:
PowerShell — Primera conversión completa
Set-Location "C:\MarkItDownCurso"

@'
MI PRIMER DOCUMENTO

MarkItDown es una herramienta de Microsoft.

Permite convertir documentos a Markdown.

OBJETIVOS

- Aprender a convertir documentos.
- Preparar información para IA.
- Automatizar tareas.
'@ | Set-Content -Path ".\primer_documento.txt" -Encoding utf8

Get-ChildItem
markitdown ".\primer_documento.txt" -o ".\primer_documento.md"
notepad ".\primer_documento.md"

Comprender el comando y la alternativa con redirección

  • markitdown: Ejecuta la herramienta.
  • ".\primer_documento.txt": Indica el archivo de entrada.
  • -o: Opción propia de MarkItDown para especificar el archivo de salida.
  • ".\primer_documento.md": Nombre del archivo resultado.
Alternativa con redirección de PowerShell
markitdown ".\primer_documento.txt" > ".\resultado.md"

Diferencia: -o es una opción propia de MarkItDown; > es un mecanismo de salida estándar de PowerShell. Para este curso recomendamos utilizar -o.

5. Utilización mediante Línea de Comandos (CLI)

5.1. Convertir un archivo

Conversión directa
markitdown ".\documento.pdf" -o ".\documento.md"

5.2. Rutas con espacios

Las comillas permiten utilizar rutas que contienen espacios sin errores de interpretación:

Rutas entrecomilladas
markitdown "C:\Mis documentos\Informe anual.pdf" -o "C:\Mis documentos\Informe anual.md"

5.3. Consultar ayuda

Ayuda CLI
markitdown --help

5.4. Evitar sobrescribir archivos existentes

Si Test-Path ".\resultado.md" devuelve True, el archivo ya existe. Usa esta comprobación para proteger resultados previos:

PowerShell — Protección contra sobrescritura
Test-Path ".\resultado.md"

if (Test-Path ".\resultado.md") {
    Write-Host "El archivo ya existe. No se realizará la conversión."
}
else {
    markitdown ".\documento.pdf" -o ".\resultado.md"
}

5.5. Procesar varios archivos por lotes

Crea las carpetas originales y markdown y convierte automáticamente todos los PDF sin sobrescribir los ya convertidos:

PowerShell — Conversión masiva de PDF
New-Item -ItemType Directory -Path ".\originales" -Force
New-Item -ItemType Directory -Path ".\markdown" -Force

Get-ChildItem ".\originales" -Filter "*.pdf" -File | ForEach-Object {
    $salida = Join-Path ".\markdown" ($_.BaseName + ".md")

    if (-not (Test-Path $salida)) {
        markitdown $_.FullName -o $salida
    }
}

6. Los Diez Casos de Uso Guiados (10 Casos Prácticos)

Ejecuta cada caso práctico paso a paso en PowerShell con tu entorno virtual (.venv) activo.

Caso 1. Convertir un archivo de texto (.TXT)

Objetivo: Comprender el proceso básico.

PowerShell — Caso 1
Set-Location "C:\MarkItDownCurso"

@'
# Proyecto de investigación

Este proyecto estudia el uso de inteligencia artificial.

## Objetivos

- Organizar documentos.
- Extraer información.
- Preparar contenido para modelos de lenguaje.
'@ | Set-Content ".\proyecto.txt" -Encoding utf8

markitdown ".\proyecto.txt" -o ".\proyecto.md"
notepad ".\proyecto.md"
Get-Content ".\proyecto.md"

Resultado esperado: Un archivo Markdown con el contenido original. Errores: Si el archivo no existe, comprueba la carpeta; si MarkItDown no se reconoce, comprueba que el entorno está activado.

Reto y Solución: Crea otro documento sobre un tema que te interese y conviértelo utilizando el mismo procedimiento cambiando los nombres de los archivos.

Caso 2. Convertir un PDF (.PDF)

Objetivo: Extraer información de documentos PDF.

PowerShell — Caso 2
python -m pip install "markitdown[pdf]"
# Coloca informe.pdf en C:\MarkItDownCurso
markitdown ".\informe.pdf" -o ".\informe.md"
notepad ".\informe.md"

Qué debes observar: Títulos, párrafos, listas, tablas y orden de lectura.

  • PDF con texto seleccionable: Es el caso más favorable; extrae el texto contenido.
  • PDF escaneado: Puede contener fotografías de páginas en lugar de texto digital. MarkItDown no debe confundirse con una solución OCR (Optical Character Recognition) universal; puede necesitar una herramienta OCR especializada.
  • Tablas, columnas e imágenes: Comprueba que filas y columnas mantengan sus relaciones; varias columnas pueden alterar el orden de lectura; no presupongas que todo el contenido visual será recuperado.

Reto y Solución: Convierte dos PDF diferentes (uno digital y otro escaneado) y compara. El digital ofrecerá mejores resultados; el escaneado necesitará OCR.

Caso 3. Convertir Word (.DOCX)

Objetivo: Convertir un documento DOCX (crea empresa.docx con Título "Mi empresa", Subtítulo "Servicios", párrafos, lista y tabla de 3 columnas).

PowerShell — Caso 3
python -m pip install "markitdown[docx]"
markitdown ".\empresa.docx" -o ".\empresa.md"
notepad ".\empresa.md"

Comprueba: Títulos, párrafos, listas y tablas. Limitaciones: La tipografía, colores y distribución de página no tienen por qué conservarse. Reto: Crea un Word con 2 títulos, 3 párrafos y 1 tabla y verifica el Markdown.

Caso 4. Convertir PowerPoint (.PPTX)

Objetivo: Extraer contenido de presentaciones (crea presentacion.pptx con 3 diapositivas: 1. Presentación, 2. Objetivos, 3. Conclusiones).

PowerShell — Caso 4
python -m pip install "markitdown[pptx]"
markitdown ".\presentacion.pptx" -o ".\presentacion.md"
notepad ".\presentacion.md"

Extrae: Texto, títulos y contenido de diapositivas. Pierde: Animaciones, transiciones, posiciones exactas y distribución visual. Las notas del presentador no deben darse por garantizadas sin comprobar la versión. Reto: Crea una presentación sobre IA y conviértela.

Caso 5. Convertir Excel (.XLSX)

Objetivo: Extraer información de hojas de cálculo. Crea ventas.xlsx con la tabla: PRODUCTO | UNIDADES | PRECIO (Mesa 4 100, Silla 8 35, Armario 2 250).

PowerShell — Caso 5
python -m pip install "markitdown[xlsx]"
markitdown ".\ventas.xlsx" -o ".\ventas.md"
notepad ".\ventas.md"

Conceptos: Hoja (pestaña), Fila (horizontal), Columna (vertical), Fórmula (instrucción de cálculo). Limitaciones: Gráficos, formatos y fórmulas pueden no representarse igual; comprueba siempre los valores importantes. Reto: Añade una segunda hoja con otros productos y comprueba si ambas aparecen.

Caso 6. Convertir CSV y JSON (.CSV / .JSON)

Objetivo: Comprender dos formatos habituales de intercambio de datos (CSV para datos tabulares; JSON para propiedades, valores, listas y objetos).

Caso 7. Convertir HTML (.HTML)

Objetivo: Convertir una página HTML guardada localmente.

PowerShell — Caso 7
@'
<!DOCTYPE html>
<html lang="es">
<head>
<meta charset="UTF-8">
<title>Mi página</title>
</head>

Caso 8. Imágenes y OCR (.JPG / .PNG)

PowerShell — Caso 8
markitdown ".\foto.jpg" -o ".\foto.md"
notepad ".\foto.md"

Reto y Solución: Fotografía un documento con texto y compara metadatos con texto visible. Si el texto no aparece, no es un fallo: falta OCR.

Caso 9. Audio y YouTube (.WAV / .MP3 / URL)

Caso 10. Crear una Biblioteca Preparada para IA y RAG

Objetivo: Construir una biblioteca documental estructurada y analizarla con IA.

PowerShell — Estructura de Biblioteca
New-Item -ItemType Directory -Path ".\originales" -Force
New-Item -ItemType Directory -Path ".\markdown" -Force
New-Item -ItemType Directory -Path ".\informes" -Force
New-Item -ItemType Directory -Path ".\scripts" -Force

Get-ChildItem ".\originales" -Filter "*.pdf" -File | ForEach-Object {
    $destino = Join-Path ".\markdown" ($_.BaseName + ".md")
    if (-not (Test-Path $destino)) {
        markitdown $_.FullName -o $destino
    }
}

Flujo de trabajo completo: 1. Copiar documentos a originales → 2. Convertir → 3. Revisar → 4. Identificar errores (vacíos, tablas incompletas, desorden, OCR) → 5. Organizar con nombres claros (contrato_2026.md, manual_equipo.md, presupuesto_enero.md, investigacion_ia.md) → 6. Consultar a una IA → 7. Contrastar siempre con el original.

¿Qué es RAG (Retrieval-Augmented Generation)?
1. Recibir documentos → 2. Extraer contenido → 3. Dividir en fragmentos → 4. Crear representaciones vectoriales → 5. Guardar en base de datos → 6. Recuperar fragmentos relevantes → 7. Entregar a LLM → 8. Generar respuesta.
MARKITDOWN NO ES UN SISTEMA RAG: Participa únicamente en la etapa de preparación documental.

7.2. Diferencia entre CLI y API

  • CLI (Command Line Interface): Se utiliza escribiendo comandos directos en PowerShell; ideal para conversiones directas.
  • API (Application Programming Interface): Permite que otro programa Python utilice las funciones de MarkItDown dentro de aplicaciones propias.

7.3. Primer programa Python (convertir.py)

Objetivo: Crear un programa en C:\MarkItDownCurso\convertir.py que convierta un documento y guarde el resultado con el entorno virtual activado:

Python — C:\MarkItDownCurso\convertir.py
from pathlib import Path
from markitdown import MarkItDown

carpeta = Path(__file__).parent

archivo_entrada = carpeta / "proyecto.txt"
archivo_salida = carpeta / "proyecto_python.md"

if not archivo_entrada.exists():
    print("ERROR: No se encuentra el documento original.")
    raise SystemExit(1)

convertidor = MarkItDown()

resultado = convertidor.convert(str(archivo_entrada))

contenido = resultado.markdown

archivo_salida.write_text(contenido, encoding="utf-8")

print("Conversión terminada.")
print(f"Archivo creado: {archivo_salida}")
PowerShell — Ejecutar y abrir resultado
python ".\convertir.py"
notepad ".\proyecto_python.md"
  • from pathlib import Path: Importa herramientas para trabajar con rutas.
  • from markitdown import MarkItDown: Importa la clase principal.
  • carpeta = Path(__file__).parent: Identifica la carpeta donde está el programa.
  • MarkItDown() y convert(): Crea el convertidor y realiza la conversión.
  • resultado.markdown y write_text(): Contiene el texto Markdown generado y lo guarda en UTF-8.

7.4. Integraciones y 7.5. Plugins

MarkItDown puede integrarse en aplicaciones Python, procesadores documentales, sistemas de automatización, flujos de IA, búsqueda y preparación para RAG. Además admite plugins de terceros (desactivados por defecto):

PowerShell — Gestión de plugins
markitdown --list-plugins
markitdown --use-plugins ".\documento.pdf"

No instales plugins desconocidos sin revisar su código y procedencia.

7.6. Seguridad y Privacidad (10 Buenas Prácticas)

MarkItDown realiza operaciones de entrada y salida utilizando los permisos del proceso que lo ejecuta. Un programa que procesa documentos desconocidos puede acceder a recursos disponibles para el usuario:

  1. Procesa documentos de procedencia conocida.
  2. Utiliza carpetas de trabajo controladas.
  3. No ejecutes archivos desconocidos.
  4. Mantén copias de los originales.
  5. No compartas documentos confidenciales sin autorización.
  6. Protege las claves API (nunca las publiques en GitHub ni en documentos compartidos).
  7. Comprueba los servicios externos utilizados (la extracción básica es local, pero la descripción de imágenes o transcripciones pueden usar servicios en la nube).
  8. Revisa los plugins.
  9. Mantén actualizadas las dependencias.
  10. Limita los permisos cuando trabajes con documentos de terceros.

Para extraer contenido de documentos y prepararlo para sistemas de análisis, búsqueda e inteligencia artificial.

Es un formato de texto estructurado que utiliza símbolos sencillos para representar títulos, listas, enlaces y tablas.

Porque proporciona contenido textual organizado y relativamente eficiente para los modelos de lenguaje.
